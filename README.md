# 👑 Princess's Fruit Crunch 🍓🍏🍇
Welcome to **Princess's Fruit Crunch**! This is a magical, 100% offline-ready match-3 puzzle game built entirely with pure HTML, CSS, and JavaScript. No external libraries, no internet connection required—just endless fruit-matching fun!
## ✨ Features
 * **10 Exciting Levels:** Journey through 10 carefully balanced levels with increasing target scores and varying move limits.
 * **Combo Multipliers:** Trigger epic cascading matches! Every consecutive automatic match multiplies your score (x2, x3, x4...) to help you reach those massive targets.
 * **Responsive & Mobile-Friendly:** Fully supports swipe gestures for touchscreens (mobile/tablet) and mouse drag for desktop users.
 * **Custom Custom Scoring System:** Different fruits hold different magical values (see below!).
 * **The Royal Surprise:** Conquer the ultimate challenge of Level 10 to unlock a special, surprising gift! 🎁
 * **100% Offline:** Uses inline CSS and native emojis instead of image files, making it incredibly fast and completely functional without an internet connection.
## 🍎 Scoring System
Match 3 or more of the same fruits to score points. Here is the value of each fruit:
 * 🍓 **Strawberry:** 5 points
 * 🍋 **Lemon:** 10 points
 * 🍏 **Green Apple:** 15 points
 * 🫐 **Blueberry:** 20 points
 * 🍇 **Grapes:** 25 points
 * 🍊 **Orange:** 30 points
*Pro-Tip: Rely on gravity! Letting fruits fall into automatic matches builds your Combo Multiplier, which is essential for beating the later levels!*
